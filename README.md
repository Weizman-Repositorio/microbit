# micro:bit Lab

Wiring guides for 11-year-old builders: traffic light (LEDs), servo motor, ultrasonic sensor and PIR sensor.
Each guide shows two setups: **micro:bit alone** and **with an expansion board**, plus the basic MakeCode blocks.

## Publish with GitHub Pages
1. Create a repository and upload these files (`index.html`, `style.css`, `app.js`, `README.md`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<your-user>.github.io/<repo>/`.

No build step. No dependencies. Open `index.html` to test it on your computer.

## Customize
- Texts, steps and blocks live in the `P` object in `app.js`.
- Expansion boards differ. Edit `PORTX` and the `board()` function to match yours.
